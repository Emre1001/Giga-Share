01  So geht's

Zwei Wege.
Ein Knopf.

Im selben Netz findet Giga-Share andere Geräte von selbst. Alles andere erreichst du über Freunde – egal, wo sie gerade sind.

Lokal · Finden

Geräte tauchen einfach auf.

Öffne die App, und alles im selben WLAN erscheint auf dem Radar – mit Namen und Betriebssystem. Keine IP-Adressen abtippen, kein Koppeln.

UDP-BroadcastPort 52525
Lokal · Senden

Erst fragen, dann schicken.

Der Empfänger sieht zuerst, was kommt: Namen, Größen, Absender. Erst wenn er annimmt, fließt das erste Byte. Wer will, schaltet Auto-Annahme ein.

TCPPort 52526Manifest + ACK
Online · Weltweit

Freunde, egal wo.

Freunde außerhalb deines Netzes erreichst du über ihren Code. Die Verbindung läuft direkt von Gerät zu Gerät. Steht ein Router im Weg, springt ein Relay ein – das sieht aber nur verschlüsselte Pakete.

QUICTLS 1.3NAT-TraversalRelay-Fallback
Immer · Fortsetzen

Abbruch? Weiter geht's.

WLAN weg, Laptop zugeklappt – egal. Die halbe Datei bleibt als .part liegen. Beim nächsten Versuch meldet der Empfänger, wie weit er war, und es geht genau dort weiter.

04  Freunde

Dein Code ist deine Adresse.

Kein Konto, keine Telefonnummer, keine E-Mail. Jedes Gerät hat einen eigenen Schlüssel. Daraus wird dein Freundescode – zum Weitergeben per Chat oder QR.

  • 01Einmal hinzufügen, für immer in der Liste. Umbenennen oder entfernen, wann du willst.
  • 02Der Code ist öffentlich. Er sagt, wohin – nicht, was. Mitlesen kann damit niemand.
  • 03Über Ländergrenzen, durch Router und Mobilfunk. Die App sucht sich den Weg.

05  Sicherheit

Wir können deine Dateien nicht sehen. Nicht, weil wir's versprechen – sondern weil sie nie bei uns ankommen.

Auf deinem Gerät

Verschlüsselt, bevor's losgeht.

Online-Übertragungen laufen über QUIC mit TLS 1.3. Die Schlüssel entstehen auf deinem Gerät und verlassen es nie.

Unterwegs

Direkt oder durchgereicht.

Meist findet die App einen direkten Weg. Wenn nicht, hilft ein Relay – das reicht aber nur Pakete weiter, die es selbst nicht öffnen kann.

Beim Empfänger

Erst da wieder lesbar.

Entschlüsselt wird beim Empfänger, gespeichert dort, wo er's will. Es gibt keine Kopie, die irgendwo liegen bleibt.

Ehrlich gesagt: Im lokalen Modus läuft die Übertragung unverschlüsselt über TCP – dafür verlässt sie dein Netzwerk nie. In einem fremden WLAN (Café, Hotel) nimm lieber den Online-Modus.

07  Fragen

Kurz gefragt.

Muss ich mich irgendwo anmelden?

Nein. Es gibt kein Konto und keinen Server von uns. Im Heimnetz findest du Geräte automatisch, für alles andere reicht der Freundescode.

Wie groß darf eine Datei sein?

So groß, wie der Speicher beim Empfänger es zulässt. Giga-Share setzt keine eigene Grenze, und dank Fortsetzen ist auch ein Abbruch bei 90 % kein Drama.

Das andere Gerät taucht nicht auf. Was tun?

Beide Geräte müssen im selben Netz sein – manche Router trennen Gast-WLAN und Hauptnetz. Prüfe außerdem, ob die Firewall UDP 52525 und TCP 52526 durchlässt. Klappt es trotzdem nicht: Online-Modus nehmen, der funktioniert über jedes Netz.

Ist das wirklich kostenlos?

Ja. Giga-Share steht unter MIT-Lizenz, der Code liegt offen auf GitHub. Keine Werbung, kein Abo, kein Tracking.

Geht das auch mit dem iPhone?

Noch nicht. Aktuell gibt es Windows und Android, macOS und Linux folgen. iOS steht auf der Wunschliste – sag Bescheid, wenn du's brauchst.

Was sieht das Relay, wenn es einspringt?

Nur verschlüsselte Pakete und wohin sie gehen. Den Inhalt kann es nicht lesen, weil die Verschlüsselung zwischen den beiden Geräten ausgehandelt wird.
