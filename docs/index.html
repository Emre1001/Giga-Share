Gleichzeitige Übertragungen

Gleichzeitig an mehrere Geräte senden. Jede Übertragung einzeln verfolgen – mit Echtzeit-Geschwindigkeitsgraph und ETA pro Datei.

E2E-Verschlüsselt

Alle Online-Übertragungen nutzen TLS 1.3 via QUIC. Deine Dateien berühren niemals einen Cloud-Server. Keine Daten, keine Logs.

↩️

Übertragungswiederaufnahme

Verbindung bei 3,9 GB von 4 GB getrennt? Genau dort weitermachen, wo aufgehört wurde. Teildateien als .part gespeichert bis Abschluss.

Windows „Senden an"

Drag & Drop

Dateien direkt auf einen Peer im Radar oder auf einen Freund in der Liste ziehen. Übertragung startet sofort, keine Dialoge nötig.

📷

QR-Code-Pairing

Freunde durch Scannen eines QR-Codes hinzufügen. Kein Eintippen von 64-Zeichen-Codes. Einfach scannen und loslegen.

Geschwindigkeitslimit

Separate Mbit/s-Limits für LAN und Online-Übertragungen setzen. Netzwerk verfügbar halten, während riesige Dateien geteilt werden.

📦

Portabler Modus

Auf Windows von einem USB-Stick ausführen. portable.marker neben die .exe legen – Konfiguration wird daneben gespeichert. Kein Setup nötig.

Protokoll

Zwei Modi.
Eine App.

LAN für maximale Geschwindigkeit im Netzwerk. Online für verschlüsseltes P2P überall auf der Welt.

📡
LAN-Modus
Gleiches WLAN · UDP + TCP
1
Broadcast-Erkennung
Giga-Share sendet GIGASHARE_V2:{name}|{type}|{port}|{os} per UDP auf Port 52525 alle 3 Sekunden.
2
Peer-Auswahl
Geräte erscheinen mit OS-Icon und Name auf dem Radar. Peer antippen oder Dateien draufziehen.
3
TCP-Übertragung
Manifest wird zuerst gesendet (Dateiliste + Größen), Empfänger sendet ACK + Wiederaufnahme-Offsets, dann Rohdaten mit voller LAN-Geschwindigkeit.
🌐
Online-Modus
Weltweit · QUIC + E2E
1
Freund hinzufügen
Freundescodes (Ed25519-öffentliche Schlüssel) austauschen oder QR-Code mit der Kamera scannen. Freundesliste bleibt dauerhaft gespeichert.
2
NAT-Traversal
iroh behandelt STUN-Hole-Punching automatisch. Fällt auf DERP-Relay zurück wenn Direktverbindung fehlschlägt. Funktioniert hinter Firewalls.
3
QUIC-Übertragung
Gleiches Manifest- + Wiederaufnahme-Protokoll über bidirektionale QUIC-Streams. TLS 1.3 Ende-zu-Ende verschlüsselt. Kein Server sieht je deine Dateien.
Sicherheit

Zero-Knowledge.
Zero Trust erforderlich.

Giga-Share nutzt iroh's QUIC-Implementierung mit TLS 1.3. Jedes Byte wird verschlüsselt, bevor es dein Gerät verlässt. Kein Server. Kein Konto. Keine Möglichkeit, deine Dateien zu sehen.
